# 🎮 PSP Cloud Player

منصة ويب سحابية لجمع ألعاب **بلايستيشن بورتبل (PSP)** عبر روابط تحميل مباشر، وتشغيلها فوراً داخل المتصفح عبر محاكي **PPSSPP** المدمج (WebAssembly) — من دون تنزيل أي ملفات على جهاز اللاعب.

## ✨ المميزات

- **➕ إضافة عن طريق رابط مباشر:** الصق رابط تحميل مباشر (Direct Link) لملف اللعبة وسيقوم الخادم بتنزيلها في الخلفية مع شريط تقدم مباشر.
- **📦 الصيغ المدعومة:** `ISO` · `CSO` · `PBP` · `CHD` — وكذلك ملفات `ZIP` (يتم فك ضغطها تلقائياً واستخراج ملف اللعبة).
- **🖼️ مكتبة ألعاب جميلة:** عرض كل لعبة بصورتها واسمها، مع توليد غلاف افتراضي أنيق تلقائياً إذا لم ترفع صورة.
- **⚙️ شاشة إعدادات قبل اللعب:** ملء الشاشة التلقائي، مكان حفظ الحالات، معالجات صور (CRT / تكبير حاد)، أزرار اللمس للجوال، وترجيع اللعب.
- **▶️ تشغيل فوري بملء الشاشة:** المحاكي يعمل داخل المتصفح مباشرة، مع أزرار لمس افتراضية على الهاتف ولوحة مفاتيح على الحاسب.
- **🧹 إدارة كاملة:** حذف الألعاب (ملف + غلاف) من التخزين، متابعة التحميلات الأخيرة، وحماية اختيارية بكلمة مرور.
- **💾 تخزين دائم:** كل شيء (الألعاب + الأغلفة + قاعدة البيانات) يُحفظ في مجلد واحد قابل للربط بـ Railway Volume.

## 🧱 التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui |
| المحاكي | [EmulatorJS](https://emulatorjs.org) بنواة `ppsspp` (WASM) عبر CDN |
| الخادم | Next.js API Routes (Node.js) — تنزيل تدفقي + بث ملفات مع دعم Range |
| قاعدة البيانات | Prisma ORM + SQLite |
| النشر | Docker (multi-stage) جاهز لـ [Railway](https://railway.app) |

## 🚀 النشر على Railway (خطوة بخطوة)

### 1️⃣ أنشئ مشروعاً جديداً
1. ادخل إلى [railway.app](https://railway.app) وسجّل الدخول.
2. اضغط **New Project** ← **Deploy from GitHub repo**.
3. اختر مستودع **psp-cloud-player** (سيكتشف Railway ملف `railway.json` ويبني المشروع عبر Dockerfile تلقائياً).

### 2️⃣ اربط وحدة تخزين دائمة (Volume) — مهم جداً ⚠️
بدون Volume ستفقد الألعاب عند كل إعادة نشر:

1. من لوحة المشروع اضغط على الخدمة (Service) ← تبويب **Settings**.
2. انزل إلى **Volumes** ← **+ New Volume**.
3. اضبط مسار التثبيت (Mount Path) على:
   ```
   /data
   ```

### 3️⃣ أضف متغيرات البيئة
من تبويب **Variables** أضف:

| المتغير | القيمة | الوصف |
|---|---|---|
| `DATABASE_URL` | `file:/data/games.db` | مسار قاعدة البيانات داخل الـ Volume |
| `DATA_DIR` | `/data` | مجلد تخزين الألعاب والأغلفة |
| `ADMIN_PASSWORD` | كلمة مرور من اختيارك | حماية الإضافة/الحذف (اختياري لكن **مُوصى به**) |
| `MAX_GAME_SIZE_GB` | `4` | الحد الأقصى لحجم اللعبة الواحدة (اختياري) |

### 4️⃣ افتح الموقع
من تبويب **Settings** ← **Networking** ← **Generate Domain**. ستحصل على رابط مثل:
```
https://psp-cloud-player-production.up.railway.app
```

> 💡 **ملاحظة:** إذا رغبت بالنشر على منصة أخرى، ملف `Dockerfile` يعمل في أي مكان يدعم Docker.

## 📖 طريقة الاستخدام

### إضافة لعبة
1. من الصفحة الرئيسية اضغط **"إضافة لعبة"**.
2. الصق **رابط التحميل المباشر** للعبة (مثل رابط `.iso` أو `.zip` يحتوي اللعبة).
3. أضف اسم اللعبة ورابط صورة غلاف (اختياري — إن تركتها فارغة سيُولّد غلاف تلقائي).
4. اضغط **"إضافة إلى المكتبة"** وتابع شريط التقدم — عند الاكتمال تظهر اللعبة في المكتبة مباشرة.

### اللعب
1. اختر اللعبة من قائمة المكتبة.
2. اضبط الإعدادات (ملء الشاشة، المعالج المرئي، أزرار اللمس...).
3. اضغط **"بدء اللعب"** — ستتكبر الشاشة وينطلق المحاكي مباشرة.
4. داخل اللعبة: زر القائمة في الأسفل يتيح حفظ/تحميل الحالات وتغيير إعدادات المحاكي.

### أزرار التحكم الافتراضية (الجوال)
- عصا يسار = عصا PSP التناظرية · **X/O/□/△** = أزرار الأفعال
- **START / SELECT** في الأسفل · اسحب من الحافة لفتح قائمة المحاكي


## ⚙️ كيف يعمل النظام؟

```
رابط مباشر ──▶ الخادم (تنزيل تدفقي + فك ZIP) ──▶ التخزين /data
                                                    │
المتصفح ◀── بث الملف (HTTP Range) ◀── API /api/games/:id/file
    │
    └──▶ EmulatorJS (ppsspp-wasm) يشغّل اللعبة في المتصفح
```

- **التنزيل:** يتم في الخلفية على الخادم مع تتبع التقدم (بدون حجب الواجهة).
- **البث:** ملف اللعبة يُبث للمتصفح مع دعم `Range Requests` للمقاطع الكبيرة.
- **التشغيل:** المحاكي يعمل على جهاز اللاعب (client-side) — الخادم يخزن ويبث فقط، لذا لا يحتاج GPU أو مواصفات عالية.
- **الحفظ:** حالات اللعب (Save States) تُحفظ في متصفح اللاعب (IndexedDB).

## ❓ أسئلة شائعة

**اللعبة لا تعمل بعد التحميل؟**
تأكد أن الملف ليس مجلداً مضغوطاً بعدة ملفات، وأن الصيغة من المدعومة (`iso/cso/pbp/chd`)، وأن اللعبة متوافقة مع PPSSPP نفسه.

**التحميل بطيء أو يفشل؟**
يعتمد على سرعة الخادم المصدر. بعض الروابط تتطلب ترويسات خاصة ولن تعمل — جرّب رابطاً مباشراً آخر.

**أريد رفع حد الحجم؟**
غيّر `MAX_GAME_SIZE_GB` في متغيرات البيئة، وانتبه لحجم الـ Volume لديك في Railway.

**هل يمكن اللعب من أكثر من جهاز؟**
نعم — الألعاب مخزنة في الخادم، وأي جهاز يفتح الرابط يرى نفس المكتبة. حالات الحفظ داخل اللعبة تُخزن محلياً في متصفح كل لاعب.
